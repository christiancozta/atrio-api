# Gates de execução

O gate do harness permanece desabilitado até todos os itens aplicáveis estarem
fechados.

## Release do produto

- [ ] Commit candidato limpo contém código, migrations e bases normativas.
- [ ] Imagem construída a partir do commit exato.
- [ ] Suíte limpa concluída com JUnit, ambiente e hashes.
- [ ] Versões declaradas coincidem com runtime e schema de banco.

## Instrumento

- [ ] Protocolo 1.0, schema 1.0.0 e exemplo 1.0.0 preservados.
- [ ] Emenda 01 aceita e externamente pré-registrada.
- [ ] A0–A9 implementados; A10 possui fluxo humano.
- [ ] Ordem randomizada, falhas simétricas e isolamento verificados.
- [ ] Orçamentos de chamadas/tokens definidos e aplicados antes da execução.
- [ ] Outputs e registros integrais validados contra os schemas.
- [ ] Duas passagens e fechamento temporal do gold testados sem dados finais.

## Governança

- [ ] Banco experimental isolado identificado.
- [ ] Custódia experimental separada do cofre CORPUS.
- [ ] Custodiante e avaliadores designados.
- [ ] Pools constituídos; conjunto de teste selado.
- [ ] Timestamp externo recebido e verificado.

Enquanto qualquer item obrigatório estiver aberto, Tier 0, smoke, calibração e
teste permanecem bloqueados.
