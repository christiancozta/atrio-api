# Timestamp externo

Diretório reservado ao recibo externo do pacote final.

Uma requisição `.tsq`, um hash local, um commit ou uma tag não demonstram
anterioridade. O estado permanece `PENDING` até existir uma resposta externa e,
no caso de RFC 3161, ela ser verificada contra a requisição, o manifesto e a
cadeia de confiança da TSA.

Nenhum recibo foi obtido ou simulado neste pacote.
